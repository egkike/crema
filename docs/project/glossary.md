# Glosario de Términos

## Términos del Proyecto

### A

**Affiliate (Afiliado)**
Usuario que promociona productos de otros y gana comisiones por cada venta referida.

**API (Application Programming Interface)**
Conjunto de protocolos que permiten comunicación entre el frontend y el backend.

### B

**Backend**
Parte del sistema que corre en el servidor, maneja la lógica de negocio, base de datos y servicios externos.

**Balance (Saldo)**
Cantidad de dinero disponible para un usuario, dividido en pendiente y disponible.

### C

**Commission (Comisión)**
Porcentaje del precio de venta que recibe un afiliado o creador.

**Course (Curso)**
Producto digital de tipo educativo con módulos, lecciones y seguimiento de progreso.

**Creator (Creador)**
Usuario que crea y vende productos digitales en la plataforma.

### D

**Dashboard**
Panel de control donde usuarios ven estadísticas y gestionan su cuenta.

### E

**E-book (Libro Electrónico)**
Producto digital en formato de libro electrónico.

**Endpoint**
URL específica de la API que ejecuta una acción.

### F

**Frontend**
Interfaz de usuario de la aplicación (en desarrollo).

### G

**Gateway (Pasarela)**
Servicio externo para procesar pagos (ej: Mercado Pago).

### L

**LEC (Ley de Economía del Conocimiento)**
Ley argentina (27.506) que beneficia a empresas de tecnología que invierten en I+D.

**LMS (Learning Management System)**
Sistema de gestión de aprendizaje para cursos online.

### M

**Membership (Membresía)**
Producto con acceso recurrente a contenido exclusivo.

**Middleware**
Software que intercepta requests para procesarlos antes de llegar al controller.

### O

**Order (Orden)**
Registro de una compra realizada por un usuario.

### P

**Payout (Retiro)**
Solicitud de retiro de fondos disponibles.

**Platform (Plataforma)**
El sistema Crema en sí mismo.

**Product (Producto)**
Bien digital vendido en la plataforma (curso, ebook, membresía, etc.).

**Provider (Proveedor)**
Implementación de un servicio (ej: MercadoPagoProvider).

### R

**Refund (Reembolso)**
Devolución de dinero por una compra.

**Repository (Repositorio)**
Patrón de diseño que abstrae las consultas a la base de datos.

**Role (Rol)**
Tipo de usuario: USER, CREATOR, AFFILIATE, ADMIN.

### S

**Safe-Guard**
Sistema anti-fraude que evalúa solicitudes de reembolso.

**Slug**
Identificador URL único para usuarios (ej: @username).

**Streaming**
Reproducción de video en tiempo real sin descarga completa.

### T

**2FA (Two-Factor Authentication)**
Autenticación de dos factores para mayor seguridad.

**Token**
Credencial temporal para autenticar requests.

### U

**User (Usuario)**
Cualquier persona registrada en la plataforma.
